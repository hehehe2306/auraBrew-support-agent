## 為什麼和單元 6 不一樣

單元 6 每輪都是「從零抽取」，沒有記憶。單元 7 的新難題只有一個：**第 2 輪使用者只說「我 22 歲」時，第 1 輪抽到的性別、職業要還在**。所以核心是「記住＋合併」，不是抽取。

## 流程：設計 vs 實際

設計（建造前）：

```
Start → Get variable → LLM 抽取 → Code 合併 → Set variable → Condition
     ├ 有缺 → LLM 追問 → Output → End
     └ 齊了 → Knowledge retrieval → LLM 回應 → Output → End
```

實際建好的（完整流程圖見學習文件附圖 1）：

```
Start → LLM 抽取 → Code 合併 → Variable assign → Condition
     ├ If（missing 為空）→ Knowledge retrieval → LLM_1（回應）→ End
     └ Else            → LLM_2（追問）            → End
```

| 項目 | 設計時 | 實際 | 狀態 |
| :- | :- | :- | :- |
| 讀記憶 | 一個獨立的 Get variable 節點 | **沒有這個節點**：Code 節點的輸入直接從引用選單選 User variable（`o_gender` 等）就能讀 | 已實測（M0：讀到第 1 輪的值） |
| 寫記憶 | Set variable | 叫 **Variable assign**，四列 `gender/occupation/age/course ← Code` 的合併結果；寫入對象只能選已存在的 User/App variable | 已建；寫入是否正確只間接看到（第 2 輪讀到第 1 輪的性別），**第 2 輪寫入的 age 要到第 3 輪才驗，未測** |
| 變數類型 | 「用 Coze 的變數」 | 建在 **User variable**。App variable 的說明是「每次新請求都初始化」，不能跨輪 | User variable 跨輪保留：已實測 |
| 合併 | Code 節點，「待試，不確定能不能用」 | Code 節點**能用**，語言是 JavaScript；8 個輸入（本輪 4 欄 `n_*` ＋記住的 4 欄 `o_*`），5 個輸出（4 欄＋`missing`） | 已實測（M0） |
| 條件判斷 | Condition「缺的清單是否為空」 | `Code.missing` **is empty** → If 分支（查知識庫）；否則 Else（追問） | 兩輪都走 Else；If 分支**未實測** |
| 追問 | LLM「輸入缺哪些、已知哪些」 | LLM_2，**只吃 `missing`**（沒給已知欄位）；Prompt：只問缺的其中一個、不回答課程問題 | 已實測 2 輪（只問缺的，沒重問性別）；樣本太小 |
| 知識庫查詢 | Knowledge retrieval，查詢字串＝course | 查詢字串 ← `Code.course`；Hybrid；**關閉 Query Rewriting**（設計時沒想到這個選項） | 已建，**未實測** |
| 回應 | LLM「只依檢索結果回答」 | LLM_1，輸入 `kb`（檢索結果）與 `course`；Prompt：沒提到就說沒資料、不編造 | 已建，**未實測** |
| 輸出格式 | 沒設計到 | 兩個 LLM 的輸出格式改成 **Text**（預設是 JSON） | 已建 |
| 結尾 | Output → End | **沒有獨立 Output 節點**；End 用 Return text，變數 `output`（←LLM_1）、`ask`（←LLM_2），模板 `{{output}}{{ask}}` | 沒跑到的那條是否為空字串：**未驗證** |
| 欄位型別 | 沒想到 | 單元 6 的結論沿用：age 是字串 | — |

## 設計取捨：當初的預期 vs 現在能說什麼

1. **合併用 Code，不用 LLM。**預期是「規則固定、不會漏」。現在：Code 節點能跑，M0 證明這個合併在一組輸入上正確；沒做 LLM 合併的對照，所以「LLM 合併比較差」仍然只是設計理由，不是實測結論。
2. **記憶用變數，並先單獨測寫入/讀出。**實際先建完整個流程才測，M0 是用前兩輪對話代替。結果：讀得到（附圖 4）。這個順序和原計畫不同：原計畫是「不通過就不往下建」，實際是已經建完才驗證。
3. **追問每次只問一件事。**兩輪看起來有做到（每輪都只問職業），但這不是對照實驗。
4. **回應限定只依檢索結果。**未實測。
