## 講稿

**【1 標題，15 秒】**

我的期末專題是「IBKR 個人財務分析助理」。它只做分析與稽查，不下單。

**【2 專題目標，50 秒】**

這個 Agent 讀 IBKR 模擬帳戶的持倉與餘額，結合利率、匯率，解釋保證金和利差的風險，最後**稽查數字有沒有算錯**。下單和槓桿水位由人決定。下面這條是我要驗算的保證金鏈：持倉變動影響 ELV，ELV 減初始保證金是 Available Funds，減維持保證金是 Excess Liquidity，Available Funds 乘 4 是購買力。**這條鏈全是加減乘，所以可以寫成程式驗算。**選這題的原因是我自己會用，而且老師提醒金融題要看流動性、維持率和槓桿，不能只看價格。

**【3 分工，45 秒】**

設計的核心是**不同的事交給不同的角色**。能寫成公式的交給程式；要理解語意的，像判斷使用者問的是持倉還是保證金、再用白話解釋，交給 LLM；判錯代價大的，像下單與槓桿水位，交給人。這個分工的依據來自課程單元 5、6：模型可能選錯工具，流程節點裡的 LLM 也可能出錯，所以不能讓它決定不能出錯的步驟。注意，這目前是設計方向，還沒有驗證。

**【4 學習綱要，45 秒】**

老師要我先做 IBKR 的系統學習，所以我列了九個方向，分四組。A 組帳戶機制：資金基礎、流動性、維持保證金、購買力。B 組資產：看股、看債、外幣借款與利差。C 組動作：下單，只學不做。D 組是把它變成 Agent：資料接口與稽查。前八項我都對照過 IBKR 官方頁面，債券的部分還沒讀完。

**【5 進度，50 秒】**

專題這邊目前做到兩件事。第一，保證金鏈各項定義已對照官方頁面。第二，我讀到模擬帳戶摘要，**購買力剛好等於 Available Funds 乘 4**。課程的 Coze 練習只是支撐，用來決定分工。還沒做的是：持倉與保證金驗算，因為帳戶目前沒有持倉；驗算程式；Token 成本估算；使用者驗證。

**【6 問題與解決狀態，70 秒】**

遇到三個問題。第一，**沒有資料**：我的真實帳戶沒存款，所以改用模擬帳戶，現在讀得到，這題已解決。第二，**購買力公式兩頁官方說法不一致**：一個是 Available Funds 乘 4，一個多了「取前一日 ELV 較低者」。我讀到的數字吻合乘 4，但帳戶沒持倉、保證金是 0，兩個算式可能算出同樣的結果，所以我**還不能說另一個算式是錯的**，這題只算部分解決。第三，**Token 成本和使用者驗證**，還沒做。

**【7 下一步，25 秒】**

下一步：取得有持倉的模擬帳戶數字，把保證金鏈寫成驗算程式；補上老師要求的槓桿評估，並問清楚「風險係數」的定義；估一次完整分析的 Token 用量。我也會預留時間做展示。謝謝。

## 如果被問，可以這樣答

- **為什麼不讓 LLM 直接算保證金？** 這條鏈是確定性的公式，程式算得對又能驗證；LLM 算錯你看不出來，稽查就是要抓這種錯。
- **這個分工你怎麼知道對？** 目前不知道，這是設計方向，要等有持倉的資料和驗算程式才能驗證。
- **兩個購買力算式怎麼分？** 要有持倉的帳戶。目前帳戶是空的，兩個算式算出的數可能一樣。
- **風險係數是什麼？** 老師提過要加，但我不知道他指的定義，所以不自己編，要先問清楚。
- **Agent 會不會給投資建議？** 不會，只解釋保證金和利差怎麼算、稽查數字，下單與槓桿由人決定。
- **為什麼不放帳戶數字？** 我自己設的限制：帳戶資料不進簡報與文件。
